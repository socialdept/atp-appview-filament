# Records and lexicons

Part of the [atp-appview-filament docs](../introduction.md#documentation). The Records page, the JSON viewer and the Lexicons page.

## Records

The index a collection at a time, companion collections such as profiles included, filtered by repo, tombstones or hidden records, with each record in a JSON viewer. When the app has atp-appview's moderation feature on, a column shows each record's labels, colored by what they do.

## The JSON viewer

Records, payloads and schemas open in a JSON viewer that highlights the value and links what can be followed: AT-URIs and DIDs, web URLs, blobs on the repo's PDS, and a `$type` naming a followed lexicon.

## Lexicons

The followed lexicons, the revision in use and any new version held back, with its breaking changes listed and an Accept anyway button. Check one or all for new versions from the page. The navigation shows how many versions are held back.
